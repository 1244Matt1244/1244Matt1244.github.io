## 🧪 Development Approach

I treat my repositories as evolving software projects rather than finished code samples.

For selected projects, I am progressively working through:

```text
Original implementation
        ↓
Refactoring
        ↓
Improved architecture
        ↓
Testing
        ↓
Validation & error handling
        ↓
Security
        ↓
Performance
        ↓
CI/CD
        ↓
Production-oriented implementation
```

The goal is not simply to add more technologies, but to improve code quality, maintainability, reliability and understanding of software engineering practices.
